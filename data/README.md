# Obtenção dos dados

Coloque os arquivos abaixo em `data/raw/`:

1. `trashnet_dataset_resized.zip`
   - Fonte: https://github.com/garythung/trashnet
2. `realwaste.zip`
   - Fonte: https://archive.ics.uci.edu/dataset/908/realwaste

Os dados são extraídos automaticamente por `run_pipeline.py`.

As bases não são versionadas devido ao tamanho e às condições de distribuição. O código utiliza somente seis classes equivalentes entre as duas fontes.
